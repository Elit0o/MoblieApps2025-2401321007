# BotOps – Fleet Management Android Application

## 1. Идея на проекта
BotOps е професионална система за управление на флота от автономни роботи, която позволява проследяване в реално време, управление на зони, задачи и маршрутни точки (waypoints) чрез модерна мобилна апликация.

## 2. Как работи
Приложението използва Offline-First архитектура, съчетаваща локална Room база данни (Single Source of Truth) с облачна синхронизация към Firebase Firestore. Фоновият симулаторен двигател управлява живота на батериите, движението и прогреса на задачите в реално време.

## 3. Архитектура
- **Pattern:** MVVM (Model-View-ViewModel) + Repository Pattern.
- **Data Layer:** Room Database (SQLite) + Firestore Cloud Sync + SharedPreferences за локални tombstones при изтриване.
- **UI Layer:** Jetpack Navigation, Material 3 (с пълна поддръжка на Light/Dark теми), Custom 2D Canvas (`ZoneMapView`).

## 4. Потребителски поток (User Flow)
1. Потребителят стартира приложението и вижда **Централното табло (Dashboard)** с основните метрики.
2. От долната навигация може да премине към **Зони**, където се дефинират помещенията с координатни граници (Min/Max X/Y).
3. В секцията **Роботи** се управлява флота (статуси, батерия, зони).
4. В секцията **Маршрутни точки (Waypoints)** се избират точките на картата чрез интерактивен 2D мапър.
5. В секцията **Задачи** се възлагат задачи с приоритети, като приложението следи прогреса и автоматично ги придвижва.

## 5. Стъпки за стартиране
1. Клонирай репозиторито
2. Отвори проекта в **Android Studio** (най-нова стабилна версия).
3. Изчакай Gradle да синхронизира зависимостите.
4. Стартирай приложението на физическо устройство или емулатор (Min SDK 24+).

## 6. Тестови акаунти / Данни
Приложението е Offline-First и автоматично инициализира начални примерни данни при първо стартиране в локалната Room база.
